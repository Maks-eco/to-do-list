## To-Do List

**Строго типизированный блокнот задач, созданный для наработки навыков компонентной архитектуры.**

## Демо

Посмотреть проект вживую можно по ссылке: [maks-eco.github.io/to-do-list/](https://maks-eco.github.io/to-do-list/)

## Технологии и Особенности

- **TypeScript** — строгая типизация для повышения надежности и поддержки кода.
- **Компонентная архитектура (Feature-Sliced Design)** — масштабируемая структура и разделение логики интерфейса.
- **Webpack** — сборка и оптимизация всех ресурсов проекта.
